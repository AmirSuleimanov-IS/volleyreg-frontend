# VolleyReg — фронтенд

SPA для системы регистрации команд на Первенство ЗГУ по волейболу 2026 (тема 16: участники и заявки команд).

Стек: React 18, TypeScript, Vite, React-Bootstrap, react-router-dom. Каждая лабораторная работа — отдельная ветка (`lab5-volley-spa`, `lab6-volley-fetch`, …).

```
npm install
npm run dev     # http://localhost:3000
npm run build
```

Бэкенд: репозиторий `volleyreg-backend`.
